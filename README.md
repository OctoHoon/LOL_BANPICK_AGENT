# 밴픽 도우미 (첫 버전)

팀원 5명의 챔프폭을 적어 두면 리그 오브 레전드 밴픽 중에 밴할 챔피언과 누가 무엇을 고를지 추천하는 웹앱이다. 빌드 과정이 없는 정적 웹앱이라 파일을 그대로 올리면 동작한다.

## 바로 써 보기

```bash
python3 -m http.server 5173      # 또는 npm run dev
# 브라우저에서 http://localhost:5173
```

`index.html` 을 파일로 바로 열면 브라우저 보안 정책 때문에 동작하지 않는다. 위처럼 간단한 서버로 열어야 한다.

## 기능

- 팀 챔프폭: 팀원별 라인, 챔피언과 숙련도(주력·가능·연습), 최근 전적(승/판), 상대하기 싫은 챔피언
- 경계 챔피언 목록: 팀이 직접 관리하는 밴 후보. 처음 들어 있는 것은 예시일 뿐 통계가 아니다.
- 밴픽 보드: 랭크 방식(양 팀 5밴 후 1-2-2-2-2-1 픽)과 대회 방식(3밴·3픽·2밴·2픽), 블루·레드 선택
- 추천: 밴 차례에는 밴 후보, 픽 차례에는 남은 팀원별 픽 후보와 이유
- 팀 공유 링크: 팀 챔프폭을 주소에 담아 팀원에게 보냄(서버 저장 없음)
- 한글 초성 검색(ㅇㄹ → 아리), 휴대폰 화면 대응

## 추천 계산 방식 (규칙 기반, 조정 가능)

`logic.js` 에 모여 있다. 수치는 첫 버전용 임의 설정이므로 써 보면서 조정한다.

- 픽: 숙련도 점수(주력 60, 가능 40, 연습 20) + 전적 보정(5판 이상, ±10) + 조합 보정(AP나 AD가 없으면 +10, 한쪽 쏠림 −10, 앞라인이 없으면 가산) + 경계 목록 선점 +6 + 여러 팀원이 다루는 챔피언 초반 +5 + 남은 주력이 하나뿐이면 +4
- 밴: 팀원이 상대하기 싫은 챔피언 +30, 경계 목록 +25부터 순서대로 감소. 우리 팀 주력·가능 챔피언은 제외
- AD/AP·앞라인 분류는 `data/champions.js` 의 수동 표를 쓰고, 표에 없는 신규 챔피언은 Data Dragon 수치로 추정한다.

## 데이터

- 챔피언 목록·한국어 이름·초상화: Riot 공식 Data Dragon. 불러오지 못하면 내장 예비 목록(약 170개)으로 동작한다.
- 팀원 전적(`data/team.json`)과 메타 통계(`data/meta.json`)는 `scripts/collect.mjs` 가 Riot 공식 API로 모은다. OP.GG 등 통계 사이트는 약관 문제로 쓰지 않는다.
- 두 파일이 없으면 앱은 직접 입력한 챔프폭만으로 동작한다.

### 수집하는 것

| 파일 | 내용 | 출처 |
|---|---|---|
| `data/team.json` | 팀원별 최근 랭크(자유·솔로) 60판의 챔피언별 판수·승수, 주 포지션, 숙련도 상위 15개, 팀원끼리 함께한 판수 | account-v1, champion-mastery-v4, match-v5 |
| `data/meta.json` | KR 챌린저~마스터 솔로 랭크의 챔피언 포지션별 판수·승수, 밴 수, 같은 라인 맞대결 상성, 원딜·서폿 듀오 궁합 | league-v4, match-v5 |
| `data/raw/` | 다음 실행 때 이어서 쌓기 위한 누적 원자료와 이미 본 경기 목록 | |

메타 통계는 한 번 실행할 때 새 경기 300판씩 쌓고, 최근 2개 패치만 남긴다. 설정은 `config/team.json`.

### 추천에 쓰는 방식

- 표본이 적은 수치는 그대로 믿지 않고 50%로 끌어당긴 보정 승률을 쓴다(포지션 승률 50판, 상성·듀오 30판 분량).
- 픽: 상위권 포지션 승률(±8), 상대 같은 라인 챔피언과의 상성(±12), 원딜·서폿 듀오 궁합(±6), 상대 라이너가 아직 안 나왔으면 크게 불리한 상대가 많은 챔피언에 소폭 감점과 「카운터 주의」 표시.
- 상대 픽의 포지션은 상위권에서 그 챔피언이 가장 많이 가는 포지션으로 추정하고, 겹치면 비중이 큰 쪽에 배정한다.
- 밴: 상위권 밴픽률과 승률, 그리고 아직 픽하지 않은 팀원의 주력 챔피언을 라인전에서 이기는 챔피언에 가산.

### 수집 실행

```bash
RIOT_API_KEY=발급받은키 node scripts/collect.mjs          # 팀원과 메타 모두
RIOT_API_KEY=발급받은키 node scripts/collect.mjs --members # 팀원만 (개발용 키로 약 7분)
```

GitHub Actions(`.github/workflows/collect.yml`)가 매일 한국 시각 05:00에 같은 일을 하고 결과를 커밋한다. 저장소 Secrets에 `RIOT_API_KEY` 를 넣어야 한다. 개발용 키는 24시간마다 만료되므로 매일 자동으로 돌리려면 Riot에 개인용 키(Personal API Key)를 신청해야 한다.

## Riot API 연동 (선택)

`api/riot.js` 는 Vercel 서버 함수다. Riot ID로 챔피언 숙련도 상위 15개를 받아 챔프폭에 추가한다. 환경 변수 `RIOT_API_KEY` 가 필요하다. 키는 브라우저 코드에 넣지 않는다.
